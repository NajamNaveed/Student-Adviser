# 🎓 Student Grade Advisor

An AI-powered web app where a student enters their marks and gets their grades, GPA, a predicted final result, and a personalized improvement plan.

Built with **Python**, **Streamlit**, **scikit-learn** and the **Google Gemini API** (free tier).

## Features

- Enter any number of subjects with marks and totals
- Automatic percentage, grade and GPA (out of 4.0)
- Detects the strongest and weakest subjects
- Bar chart of performance per subject
- Machine learning prediction of the likely final result
- Personalized improvement plan generated by Gemini
- Input validation and graceful error messages

## How it works

1. **Grading (rule-based):** marks are converted to percentage, grade and GPA with fixed thresholds.
2. **Prediction (machine learning):** a Random Forest model trained on the UCI Student Performance dataset predicts the final result from previous marks, study time, failures and absences.
3. **Advice (LLM):** the results and the prediction are sent to the Gemini API, which writes a study plan.

## Installation

1. **Clone the repository**
   ```
   git clone https://github.com/NajamNaveed/student_advisor.git
   cd student_advisor
   ```

2. **Create and activate a virtual environment**
   ```
   python -m venv venv
   venv\Scripts\activate          # Windows
   source venv/bin/activate       # Mac/Linux
   ```

3. **Install dependencies**
   ```
   pip install -r requirements.txt
   ```

4. **Add your free Gemini API key**
   - Get a key at https://aistudio.google.com/apikey
   - Copy `.env.example` to `.env` and paste your key:
     ```
     GEMINI_API_KEY=your_key_here
     ```

5. **Train the model** (only needed if `model.pkl` is missing)
   ```
   python train_model.py
   ```

6. **Run the app**
   ```
   streamlit run app.py
   ```
   Open http://localhost:8501 in your browser.

## Grading scale

| Percentage | Grade | GPA |
|---|---|---|
| 90 and above | A+ | 4.0 |
| 80 to 89 | A | 4.0 |
| 70 to 79 | B | 3.0 |
| 60 to 69 | C | 2.0 |
| 50 to 59 | D | 1.0 |
| Below 50 | F | 0.0 |

Edit `get_grade()` in `grading.py` to match your institution's scale.

## Limitations

- The model is trained on only 395 students from two Portuguese schools, so predictions are rough estimates, not guarantees.
- The AI advice is general guidance and does not replace a teacher or academic counselor.
- The free Gemini tier has rate limits, so advice may occasionally be unavailable. Grades and predictions still work.
